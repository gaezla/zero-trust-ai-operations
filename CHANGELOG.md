# Changelog

All notable changes to this specification are recorded here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the specification uses [semantic versioning](https://semver.org/) as described in [CONTRIBUTING.md](CONTRIBUTING.md#versioning).

## [1.0.0-draft.1] - 2026-10-11

First draft for public review.

### Added

- The specification: scope, conventions with a verification method that tests the platform rather than the model, terminology, a threat model with three adversaries and six security goals, two general requirements and five rules expressed as testable requirements (R0.1 to R5.7), each rule with verification steps, and a section on the residual risk a conforming system still carries.
- A conformance guide with a self-assessment statement template, a residual-risk assessment, and rules for configurable systems and draft versions.
- A crosswalk to NIST SP 800-207, the OWASP Top 10 for LLM Applications 2026, the OWASP Top 10 for Agentic Applications 2026, the Model Context Protocol specification 2026-07-28, the Agents Rule of Two, the lethal trifecta, the Agentic Trust Framework and the OWASP Agent Control Standard.
- A 25-question checklist for buyers, each question mapped to the requirements it tests.
- A citation file, issue templates and contribution guidelines.
